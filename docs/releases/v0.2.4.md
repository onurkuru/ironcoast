# Iron Coast: Scrap Tide v0.2.4 — PS Vita preview

A self-contained PS Vita homebrew package with six missions, six bosses, worker rescues, weapon pickups and the Scrap Walker vehicle.

![Iron Coast cover artwork](https://raw.githubusercontent.com/onurkuru/ironcoast/v0.2.4/docs/art/cover.jpg)

*Original launcher/promotional artwork; not a gameplay screenshot.*

## Download

- **`Iron-Coast-PSVita-v0.2.4.vpk`** — installable PS Vita game, including all assets.
- **`SHA256SUMS.txt`** — checksum for the VPK.

Title ID: `KHYI00001` · Vita application version: `00.24`. Only PS Vita binaries are distributed. GitHub's automatic source archives are not installable game packages.

## Included in this release

- Original orange-claw/cyan-core bubble icon.
- Illustrated LiveArea background, launch gate image and loading screen.
- Vita button labels in gameplay hints and navigation/controls screens.
- Boss recovery indicated by an animated core glow; no floating `CORE OPEN` label.
- Six actual game-renderer screenshots, story, campaign overview and detailed installation documentation.
- Indexed PNG, metadata, XML, archive and bundled-resource validation.

## Install

Copy the VPK to `ux0:VPK/` using VitaShell USB or FTP. Select the package in VitaShell, confirm installation, then launch **Iron Coast: Scrap Tide** from LiveArea. Keep at least 100 MB free for installation. No separate game assets or commercial game data are required.

[Full English instructions](https://github.com/onurkuru/ironcoast/tree/v0.2.4#installation) · [Ayrıntılı Türkçe kurulum](https://github.com/onurkuru/ironcoast/blob/v0.2.4/docs/INSTALL_TR.md)

Before upgrading an existing installation, close the game and back up `ux0:data/KiyiHurdasi/save.dat`. The Title ID is unchanged.

## Validation and current limits

VitaSDK cross-compilation, package validation and both host-side gameplay/render tests passed. Physical Vita installation, LiveArea display, controls, audio and performance remain unverified. This is a development preview; please report device results with model, firmware, mission and reproduction steps.

The building-led campaign redesign is research/planning only and is **not included**. The screenshots show the current playable levels; the cover illustration is promotional art.
