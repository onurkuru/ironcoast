# Iron Coast v0.2.5 — PS Vita stability preview

Fixes rescue progress disappearing after a life loss or checkpoint Continue. Rescued workers and their count now stay consistent, without duplicate rewards when revisiting them.

## Validation

- All six missions completed on foot and with vehicle boarding enabled, using real movement and weapon damage.
- 37 restart locations and 48 randomized input scenarios; 912,007 simulated update frames.
- 724 full-world renderer samples and the existing sprite/light checks.
- 13 full-application, SDL/audio and malformed-save startup cases.
- Host tests, local UBSan checks and VitaSDK compilation passed.
- Linux ASan, UBSan, float-cast-overflow, leak detection and atlas validation passed.

See the [full stability audit](https://github.com/onurkuru/ironcoast/blob/v0.2.5/docs/STABILITY_AUDIT.md) and [Linux sanitizer run](https://github.com/onurkuru/ironcoast/actions/runs/34287370100) for results and coverage limits.

## Download and install

Download **`Iron-Coast-PSVita-v0.2.5.vpk`** and optionally `SHA256SUMS.txt`. Copy the VPK to `ux0:VPK/`, install it using VitaShell and launch the Iron Coast bubble. No additional assets are needed.

Title ID remains `KHYI00001`; Vita application version is `00.25`. Back up `ux0:data/KiyiHurdasi/save.dat` before updating, then install over the previous version.
