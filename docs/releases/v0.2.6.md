# Iron Coast v0.2.6 — English-only PS Vita preview

Iron Coast uses English throughout its dialogue, interface and public documentation. This update replaces the remaining title-screen and final-mission phrases, removes the alternate-language installation guide and translates the level-design research. The README includes the English installation guide, story and gameplay screenshots.

The six-mission campaign, bosses and v0.2.5 stability fixes are retained. The architectural map redesign remains planned work.

## Download and install

Download **`Iron-Coast-PSVita-v0.2.6.vpk`** from Assets. Optionally verify it using `SHA256SUMS.txt`. Copy the VPK to `ux0:VPK/`, install it with VitaShell and launch Iron Coast. All assets and LiveArea artwork are included.

Title ID: `KHYI00001`. Vita application version: `00.26`. Existing saves remain compatible; back up `ux0:data/KiyiHurdasi/save.dat` before installing over the previous version. This legacy internal folder is retained to preserve progress.

[Installation, story and screenshots](https://github.com/onurkuru/ironcoast/tree/v0.2.6#installation)

Only PS Vita game packages are distributed. Physical Vita installation and performance testing remain pending. Host tests and package validation cannot guarantee device behavior.
