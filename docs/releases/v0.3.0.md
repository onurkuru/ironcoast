# Iron Coast v0.3.0 — Architecture and climbing preview

All six missions now have playable building and roof routes, 60 ladders, vertical camera tracking and continuous lower paths. Warehouses, pump works, freight cars, foundries and command structures replace the disconnected platform layout.

- New climbing poses and attachment/release transitions.
- 30 animated doors with finite, staggered enemy reinforcements.
- Roof and wall light occlusion, window projections and surface-specific reflections.
- Metal/water footsteps tied to movement, water splashes and improved architectural depth.
- Existing campaign, rescues and six bosses retained; all player-facing text remains English.

The four host test suites, eight atlas checks and 13 SDL/audio/save startup checks pass. Coverage includes all 60 ladder round trips, roof crossings and all 30 door encounters. VitaSDK compilation and VPK validation are performed for this release. Physical Vita performance remains unverified.

See the [architecture report](https://github.com/onurkuru/ironcoast/blob/v0.3.0/docs/ARCHITECTURE_UPDATE.md) for coverage and limitations. This is an original 2D interpretation of architectural depth and cinematic lighting; elevators and full 3D rendering are not included.

## Install

Download **`Iron-Coast-PSVita-v0.3.0.vpk`** and optionally `SHA256SUMS.txt`. Copy the VPK to `ux0:VPK/`, install with VitaShell and launch Iron Coast. All art assets and LiveArea files are included.

Title ID remains `KHYI00001`, application version `00.30`. Back up `ux0:data/KiyiHurdasi/save.dat` before updating over the existing bubble. This legacy internal folder preserves existing progress.
